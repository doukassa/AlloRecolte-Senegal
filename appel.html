Simulateur d'appel vocal

Cette page simule, dans le navigateur, l'expérience du canal vocal (IVR + assistant conversationnel), avec un vrai clavier de téléphone. La version réelle fonctionnerait par un vrai numéro de téléphone — voir le README pour le détail de ce qui est simulé.

Textes en khmer générés automatiquement pour cette démo — à faire relire par un locuteur natif avant toute utilisation réelle.
Depuis n'importe quel téléphone, le fermier compose ce numéro.
Exemples à essayer : « prix du riz », « je veux vendre ma récolte ».
